## 1. Deskripsi Proyek
Program konsol berbasis Python ini dirancang untuk membantu guru matematika dalam mengotomatisasi proses rekapitulasi nilai ujian siswa. Program membaca data dari file eksternal, melakukan validasi nilai, menghitung statistik kelas (rata-rata, minimum, maksimum), menentukan status ketuntasan berdasarkan KKM, serta menyusun laporan ringkas.
